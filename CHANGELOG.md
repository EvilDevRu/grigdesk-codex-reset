# История изменений

## 0.1.1

- Дата последнего сброса и прогноз на 24/48 часов во всплывашке Codex.
- Размещение `provider.popover.after-bars`, без отдельной страницы плагина.
- JSON-ресурсы с переводами RU/EN, ссылкой на источник и видимой пометкой давности.
- Сохранены фоновый сбор, API и остановка при выключении.

Для отображения нужна сборка окна GrigDesk с поддержкой JSON-ресурсов фоновых плагинов.

## 0.1.0

Первая версия.

- Пользовательский серверный плагин GrigDesk API 2 без интерфейса и навигации.
- Фоновый сбор последнего сброса и прогнозов codexreset.org на 24/48 часов.
- Разбор прежнего и текущего сериализатора сайта без выполнения его скриптов.
- Часовой кэш, ограничение размера ответа и повторов после ошибки.
- API снимка, событие `signal` и остановка запросов при выключении.
