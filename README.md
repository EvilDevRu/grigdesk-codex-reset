Codex Reset собирает публичные данные [codexreset.org](https://codexreset.org/):
когда сайт зафиксировал последний сброс квоты Codex и как оценивает вероятность
следующего сброса за 24 и 48 часов.

Плагин работает на сервере GrigDesk, в том числе при закрытых окнах.
Агенты и интеграции получают данные через API и общий поток событий.
Последний сброс и оценки появляются в выпадающем блоке **Codex** в верхней панели.
Отдельных экранов, панелей и пунктов навигации у плагина нет.

## Возможности

- **Последний сброс.** Дата, область действия и ссылка на первоисточник по данным сайта.
- **Прогноз на 24 и 48 часов.** Оценки codexreset.org с явным указанием источника.
- **Фоновое обновление.** Часовой кэш и один запрос для параллельных читателей.
- **Работа при сбоях.** Последний успешный ответ сохраняется в памяти с пометкой о давности и ошибке.
- **Управление из GrigDesk.** Общий тумблер останавливает опрос и отменяет текущий запрос.

Это независимый источник: прогноз сайта не подтверждает состояние квоты конкретного
аккаунта и не гарантирует следующий сброс. Собственные данные аккаунта GrigDesk
сайту не передаются.

## Установка

1. Откройте раздел плагинов GrigDesk и выберите **установку из Git**.
2. Укажите репозиторий:

   ```text
   https://github.com/EvilDevRu/grigdesk-codex-reset
   ```

3. Нажмите **«Найти версии»** и выберите **v0.1.2**.
4. Просмотрите пакет, установите и включите **Codex Reset**.

Репозиторий приватный: у владельца установки должен быть доступ к нему.
Git на машине GrigDesk должен быть авторизован. Для доступа через GitHub CLI
однократно выполните `gh auth login` и `gh auth setup-git`.

Нужен GrigDesk с единым манифестом v1 (`api: 1`), выводом JSON-ресурсов
в `provider.popover.after-bars` и Node.js 22.19 или новее.
Версии плагина до первого релиза остаются в ветке **0.1.x**.
После обновления пакета окна GrigDesk закройте приложение и откройте снова.
Установка зависимостей и сборка плагину не требуются.

## Как получать данные

Агент читает `GET /api/ext/codex-reset/signal` через авторизованный API GrigDesk.
Для снимка без ожидания сети доступен `GET /api/ext/codex-reset/status`.
Изменения приходят в общий поток как `plugin-event`, с `pluginId: codex-reset`
и `event: signal`.

Пример потребителя и формат ответа — в [документации API](docs/api.md).
Для всплывашки плагин объявляет `contributes.slots` с местом
`provider.popover.after-bars` и типом `provider-usage`
и отдаёт `GET /api/ext/codex-reset/provider-usage?providerId=codex`.
Размещение можно отдельно скрыть в общих настройках плагина.

## Разработка

```bash
GRIGDESK_SOURCE_ROOT=/absolute/path/to/grigdesk npm test
npm run check:release
npm run pack:release -- /absolute/path/to/artifacts
```

Проверка совместимости запускает настоящий runtime GrigDesk на локальных фикстурах.
Внешний сайт, платные модели и работающий экземпляр приложения для тестов не нужны.
