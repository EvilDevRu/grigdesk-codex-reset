# Настройка и использование

После установки включите Codex Reset в общем разделе плагинов GrigDesk.
Плагин не требует ключа сайта или дополнительных настроек.
Откройте выпадающий блок **Codex** в верхней панели: под полосами лимитов
появятся последний сброс по версии codexreset.org и прогноз на 24/48 часов.
Плагин не создаёт страницу, панель, пункт навигации или браузерный модуль.
Единая PNG-иконка объявлена в `icon` и используется в карточке GrigDesk
и README. SVG-исходник сохранён рядом для редактирования.

Сервер запрашивает публичную главную codexreset.org в фоне. Первый запрос
начинается после готовности плагина. Успешный ответ сохраняется в памяти на час;
при ошибке предыдущие данные доступны с `stale: true`.

Чтобы агент получил последний сброс и прогноз, используйте авторизованный
`GET /api/ext/codex-reset/signal`. `GET /api/ext/codex-reset/status` возвращает
снимок немедленно и может содержать `null` до первой успешной загрузки.
Адрес API относится к текущей установке GrigDesk: секреты сессии не помещают
в текст запроса агенту и не отправляют codexreset.org.

Выключение общего тумблера прекращает фоновый опрос, отменяет текущий запрос
и закрывает API плагина. Повторное включение восстанавливает работу.

Данные сайта описывают общие или широкие сбросы по его интерпретации публичных
свидетельств. Они не заменяют измерения личной квоты. В ответах и интеграциях
сохраняйте название источника и отмечайте устаревшие данные.

Декларация `contributes.slots` включает `provider.popover.after-bars`
с типом `provider-usage` по умолчанию. Его можно
скрыть в общих настройках плагина, сохранив фоновый сбор и API. У других
исполнителей строки плагина не появляются. Оговорка источника и давность
видны рядом с прогнозом; ссылка открывает codexreset.org.

Для отображения требуется веб-сборка GrigDesk с общим выводом JSON-ресурсов
фоновых плагинов. После обновления пакета окна закройте приложение и откройте снова. На старой
веб-сборке фоновый сбор и прежние API работают, но строки не отображаются.

При переходе с прежних версий 0.1.0–0.1.1 обновите или переустановите пакет
из того же Git-репозитория, выбрав 0.1.2 или новее из ветки 0.1.x.
Эти старые версии имеют прежнюю структуру манифеста и не исполняются новым ядром.
