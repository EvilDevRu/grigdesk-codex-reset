# Серверная интеграция API 2

Codex Reset — серверный пользовательский плагин с `api: 2`.
В пакете ровно один серверный вход `server.js`, нет `web`, `webModule` и `nav`.
Он объявляет размещение `provider.popover.after-bars` и использует стандартные `lifecycle.onDisable`, `lifecycle.onEnable`, `onClose`
и `options.core.emit` для общего события `plugin-event`.

Для отображения требуется веб-часть GrigDesk с нативным
`ProviderUsagePlugins.vue`: компонент читает JSON `/provider-usage` только
для включённого фонового плагина и его размещения. Сервер GrigDesk менять
для этого контракта не требуется. После обновления пакета окна закройте приложение и откройте снова.
Без совместимого веба доступны только сбор и API.

Сборка и runtime-зависимости отсутствуют. Требуется Node.js 22.19+ и GrigDesk
с серверным API 2, общим auth guard, lifecycle и маршрутизацией `/api/ext/<id>/`.
При выключении ядро закрывает маршруты, сам плагин останавливает таймер и запрос.

## Проверка

Путь к совместимому checkout GrigDesk передаётся явно:

```bash
GRIGDESK_SOURCE_ROOT=/absolute/path/to/grigdesk npm test
```

Тестовый скрипт запускает проверки через штатный сторож памяти GrigDesk.
Тесты источника проверяют форматы страницы, кэш, повторы, отмену, таймаут
и ограничения входных данных. Интеграционный тест создаёт временный каталог
`plugins/codex-reset` и запускает настоящий plugin runtime на фикстурах:
сканирование, фон, событие, выключение, закрытый API и повторное включение.
Рабочая установка GrigDesk и внешний сайт не меняются.

```bash
npm run check:release
npm run pack:release -- /absolute/path/to/artifacts
```

Проверка релиза сверяет версии и состав поставки. Упаковщик создаёт архив
с SHA-256, исключая Git, локальные данные и результаты проверок.
Для установки из Git содержимое корня репозитория должно совпадать с поставкой;
стабильный тег `vX.Y.Z` должен соответствовать версии `plugin.json`.
